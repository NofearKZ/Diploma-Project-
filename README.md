# Интерактивное мобильное приложение для обучения детей чтению («Легкое Чтение» / «Оңай Оқу»)

## Тема проекта / Дипломной работы
**Разработка мобильного приложения для обучения детей чтению на русском и казахском языках с использованием технологий распознавания и синтеза речи.** 

Проект представляет собой интерактивную, геймифицированную обучающую платформу, которая помогает детям младшего возраста и детям с трудностями в обучении уверенно осваивать навыки чтения. Приложение не только тренирует навыки, но и автоматизирует проверку произношения, а также предоставляет родителям подробную аналитику.

## Ключевые возможности (Features)

- **Голосовая валидация (Speech-to-Text):** Интеграция умного слушателя. Ребенок читает текст в микрофон, а приложение в реальном времени подсвечивает правильно произнесенные слова зеленым цветом и отмечает красным слова, вызвавшие трудности.
- **Аудио-сопровождение (Text-to-Speech):** Возможность озвучивания всего текста или отдельного слова для демонстрации правильного произношения. Присутствует режим замедленного чтения.
- **Поддержка чтения по слогам:** Специальный тумблер, который автоматически разбивает слова в тексте на слоги для легкого восприятия новичками.
- **Инклюзивный подход:** Крупные читаемые шрифты, увеличенные интервалы и контрастность, что снижает когнитивную нагрузку (полезно при дислексии).
- **Проверка понимания (Квизы):** Интерактивные тесты после каждого прочитанного текста с системой поощрений (награды-звездочки за правильные ответы).
- **Панель для родителей (Analytics Dashboard):** Скрытый раздел для родителей, где сохраняется подробная статистика: затраченное время, количество ошибок, прочитанные материалы и общая успеваемость.
- **Двуязычность:** Полная поддержка и переключение на лету между казахским и русским языками.
- **Детский UI/UX дизайн:** Яркий, мягкий и дружелюбный интерфейс, мотивирующий ребенка к регулярным занятиям. Оформлен в светлых тонах с использованием фигурных элементов и эмодзи-иллюстраций.

## Стек технологий (Tech Stack)

* **Платформа:** Android 
* **Язык разработки:** Kotlin
* **Пользовательский интерфейс (UI):** Jetpack Compose, Material Design 3
* **Распознавание языка (ML/AI API):** Android `SpeechRecognizer` (STT), `TextToSpeech` (TTS)
* **Архитектурный паттерн:** MVVM (Model-View-ViewModel) + StateFlow
* **База данных:** Room Database / SQLite (для хранения локального прогресса чтений и аналитики)
