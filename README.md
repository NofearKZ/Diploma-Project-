# 📚 Оңай Оқу / Легкое Чтение 

Данный проект разработан в рамках дипломной работы. Представляет собой специализированное мобильное приложение, направленное на развитие и коррекцию навыков чтения у учеников младших классов, имеющих дислексию или трудности с восприятием текста. 

## Цель проекта
Создать интерактивную, безопасную и комфортную образовательную среду, которая помогает детям преодолеть барьеры при чтении, снижает уровень стресса и повышает мотивацию к обучению через геймификацию и адаптивные визуальные настройки.

## Ключевые особенности
* **Двуязычная образовательная среда:** Полная поддержка казахского и русского языков.
* **Адаптация текста для дислексиков:** 
  * Специальное форматирование с увеличенными межстрочными интервалами.
  * Режим «Чтение по слогам» для упрощения визуального распознавания слов.
  * Цветовое выделение «трудных» слов для фокусировки внимания (красным цветом) и верно прочитанных (зеленым).
* **Распознавание речи (Speech-to-Text):** Интерактивная проверка чтения через микрофон. Приложение в реальном времени слушает ребенка и подсвечивает правильно прочитанные слова.
* **Аудио-поддержка (Text-to-Speech):** Возможность прослушать правильное произношение слова или всего текста с комфортной (замедленной) скоростью, чтобы ребенок мог ориентироваться на слух.
* **Геймификация и закрепление материала:** Викторины на понимание прочитанного после каждого текста. За правильные ответы ребенок получает визуальные награды (звездочки).
* **Родительский контроль и аналитика:** Специальный раздел, скрытый PIN-кодом, где родители и педагоги могут отслеживать статистику: скорость чтения (слов в минуту), количество совершенных ошибок и успешность прохождения викторин.
* **Дружелюбный UI/UX:** Светлый, нестрогий, "детский" дизайн, который не перегружает нервную систему и располагает к обучению.

## Стек технологий
* **Платформа:** Android (Android SDK)
* **Язык программирования:** Kotlin
* **UI-фреймворк:** Jetpack Compose (Modern Declarative UI)
* **Архитектура:** MVVM (Model-View-ViewModel) + StateFlow
* **Системные сервисы:** Android `SpeechRecognizer` (распознавание голоса), `TextToSpeech` (синтез речи)

*Проект разработан как цифровой инструмент-помощник для дефектологов, логопедов, а также родителей, занимающихся с детьми дома.*
